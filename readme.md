# Protótipo Multiplayer em Unity

Um projeto simples desenvolvido durante o treinamento em **Multiplayer para VR e Metaverso** da residência tecnológica.

## 🎮 Sobre o projeto

O projeto consiste em uma pequena sala virtual rosa, onde o jogador pode interagir com um cubo que pode ser agarrado.

O objetivo principal foi praticar conceitos básicos de **multiplayer e interação com objetos no Unity**, utilizando uma cena simples como ambiente de experimentação.

## 🛠️ Tecnologias

* **Unity 6**
* **C#**
* **Netcode for GameObjects**
* **XR Interaction Toolkit**

## ✨ Funcionalidades

* 🏠 Ambiente virtual simples
* 🧊 Cubo interativo
* ✋ Interação de agarrar o objeto
* 🌐 Experimentação de conceitos de multiplayer

## 🎯 Objetivo

Este projeto foi desenvolvido como um exercício prático sobre **Multiplayer em Realidade Virtual com Unity 6**, com foco na experimentação dos conceitos de rede e interação apresentados durante o treinamento.
